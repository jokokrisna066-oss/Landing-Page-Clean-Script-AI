# CleanScript AI

Landing page marketing statis untuk CleanScript AI — produk yang membantu membersihkan data Excel/CSV dan menghasilkan script Pandas reusable.

## Preview lokal

Jalankan server statis dari folder ini:

```bash
python3 -m http.server 8000
```

Lalu buka http://localhost:8000.

Form waitlist saat ini hanya menampilkan konfirmasi di browser. Hubungkan handler form ke endpoint/email service ketika backend sudah tersedia.
